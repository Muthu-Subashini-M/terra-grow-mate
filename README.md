# Terra Grow Mate

"Build a modern dashboard for a soil and agriculture management tool called Terraform. Include a form on the left with inputs for Soil pH (number input), Soil Texture (dropdown: Sandy, Clay, Loam), Nitrogen Level (dropdown: Low, Medium, High), and Water Availability (dropdown: Low, Medium, High). On the right side, display a results card showing crop suitability recommendations, action items, and a status alert for whether laboratory testing is required."
